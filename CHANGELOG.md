## [1.0.0] - 2026-08-07

### Added
- **FastAPI Core Engine:** RESTful API architecture with CORS, OpenAPI Swagger documentation, and health check routes.
- **Document Parser Service:** Multi-format PDF & DOCX parser with contact information extraction and section segmentation.
- **ATS Scoring Engine:** 0-100 ATS readiness matrix analyzing Action Verbs, Measurable Metrics, Hard Skills Density, Structure, and Brevity.
- **AI STAR Rewriter Service:** Bullet point rewriting engine utilizing STAR (Situation, Task, Action, Result) framework with metric additions and local NLP fallback.
- **Job Offer Matcher:** Keyword comparison engine detecting present/missing hard skills and fit percentage.
- **Cover Letter AI Generator:** Customizable cover letter creator with adjustable tone and company details.
- **LinkedIn Optimizer:** Headline option generator, About section writer, and skill recommendations.
- **Export Studio:** Formatted HTML, DOCX, and printable PDF export capabilities.
- **Next.js 14 Dashboard UI:** Modern dark/light glassmorphic UI layout built with Tailwind CSS, Lucide icons, Framer Motion, and Recharts.
