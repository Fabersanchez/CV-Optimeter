# Security Policy

## Supported Versions

We actively release security updates for the following versions of **CV Optimeter AI**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of CV Optimeter AI very seriously. If you discover a security vulnerability, please **DO NOT** create a public GitHub issue.

Instead, please send a detailed security report to **`security@cvoptimeter.ai`**.

### What to include in your report:
- Type of vulnerability (e.g., Remote Code Execution, XSS, SSRF, Information Disclosure)
- Step-by-step instructions to reproduce the issue
- Potential impact on users or systems
- Any suggested fixes or mitigations

### Disclosure Policy:
- We will acknowledge receipt of your report within 48 hours.
- We will provide a status update every 5 business days until resolution.
- Once fixed, we will publish a security advisory and credit the reporter.
