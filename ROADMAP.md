# Project Roadmap - CV Optimeter AI

This document outlines the strategic engineering roadmap and feature milestones planned for **CV Optimeter AI**.

---

## Phase 1: Core Architecture & ATS Engine (v1.0.0) — Completed :white_check_mark:
- [x] FastAPI REST API service with Swagger documentation.
- [x] PDF & DOCX text extraction with contact detection.
- [x] 0-100 ATS Scoring Engine evaluating 5 key pillars.
- [x] AI STAR Rewriter with local NLP fallback.
- [x] Job Matcher keyword gap analysis.
- [x] Next.js 14 glassmorphic dashboard UI.
- [x] Cover Letter & LinkedIn profile optimization tools.

## Phase 2: AI Enhancements & Real-Time Collaboration (v1.1.0) — Q3 2026
- [ ] Multilingual resume parsing (Spanish, English, German, French, Portuguese).
- [ ] Interactive side-by-side Visual CV Builder with drag-and-drop sections.
- [ ] Direct job post URL scraper (LinkedIn Jobs, Indeed, Glassdoor).
- [ ] Vector database integration (Qdrant / Milvus) for semantic semantic match scoring.

## Phase 3: Enterprise SaaS & API Ecosystem (v1.2.0) — Q4 2026
- [ ] OAuth2 / JWT Auth with Google, GitHub, and Enterprise SSO (SAML).
- [ ] Stripe SaaS Subscription Tiers (Free, Pro Candidate, Enterprise Recruiter).
- [ ] Team collaboration features for career coaches and university placement offices.
- [ ] Public Developer API with SDKs (Python, TypeScript).
