# CV Optimeter AI - Project Assets

This directory contains branding assets, media, design mockups, and screenshots for **CV Optimeter AI**.

## Directory Layout
- `logo/`: High-resolution vector SVG and PNG logos.
- `icons/`: Product icons and favicon assets.
- `screenshots/`: Interface screenshots used in documentation and GitHub README.
- `mockups/`: High-fidelity UI design mockups and promotional graphics.
